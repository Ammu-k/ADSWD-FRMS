# ADSWD Financial Records Management System

A secure web-based **Financial Records Management System** developed to help financial staff efficiently manage financial records. The application uses **Firebase Authentication** for secure user authentication, **Cloud Firestore** for cloud-based data storage, and is deployed using **Vercel**.

---

## 🚀 Live Demo

🌐 **Website:** https://adswd-frms.vercel.app/

---

## 📖 About the Project

The ADSWD Financial Records Management System is designed to simplify the process of managing financial records through a secure, user-friendly web application. It enables authorized financial staff to maintain records efficiently while ensuring data security and accessibility through Firebase services.

---

## 🎯 Objectives

- Provide secure access using Firebase Authentication.
- Store financial records safely in Cloud Firestore.
- Simplify financial record management.
- Enable quick searching and filtering of records.
- Generate reports and export financial data.
- Deliver a responsive and easy-to-use interface.
